How it works

Real sockets, real wire formats. NetGet speaks the protocol, whichever one it is, and the handler writes only the content: a Telnet banner, an SMTP reply, a DNS answer, a Redis value. Below, the same three run in this tab: Telnet is a client machine, netget is the dashboard, LLM is the model: the one you pick: the browser's built-in model (Gemini Nano in Chrome) or a WebLLM model on your GPU, and you until it is ready.

  1. NetGet opens a Telnet server on port 2323.
  2. The Telnet client connects to it.
  3. Everything the server says comes from the model: you, in the LLM panel, until a model is ready.
  4. Type in the Telnet terminal.
Nothing leaves this tab. The Telnet server listens on a loopback that exists only inside the WebAssembly instance, and the client connects to it through the same call a real socket would make. The browser's built-in model (Gemini Nano in Chrome, Phi-4-mini in Edge) runs on your device; a WebLLM model is downloaded once from Hugging Face and then runs on your GPU. Nothing else is fetched.
Same code as the CLI. The dashboard, the Telnet server and the LLM prompting are the native NetGet crate compiled for wasm32. The only substitutions are underneath: the executor, the clock, the sockets, and where the model's answer comes from.
You can be the model. Until a model is ready, every request NetGet makes opens a form in the LLM panel, built from the actions it offers, and your answer is what the server puts on the wire. The full prompt is one click away.

Install

MCP server for LLM agents (STDIO)

Add to claude_desktop_config.json or any MCP client config:

{
  "mcpServers": {
    "netget": {
      "command": "npx",
      "args": ["-y", "@smotana/netget", "--mcp"]
    }
  }
}

Claude Code: claude mcp add netget -- npx -y @smotana/netget --mcp

CLI

# install
npm install -g @smotana/netget            # or grab a binary from GitHub Releases

# run with local Ollama
ollama pull qwen3-coder:30b
netget

# or run against any OpenAI-compatible API
netget --openai-url https://api.openai.com --model gpt-4o --api-key $OPENAI_API_KEY

From source

git clone https://github.com/smotanacom/netget.git
cd netget

# build only the protocols you need
cargo build --release --no-default-features --features tcp,http,ssh,dns,mcp-stdio

./target/release/netget          # interactive TUI
./target/release/netget --mcp    # MCP STDIO server
