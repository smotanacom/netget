# Docker client evidence

Required independent peer: an actual Docker Engine daemon supporting API1.47 and Docker CLI in PATH. No skip if unavailable. Test fixture resolves the active Docker CLI context's Unix socket with read-only `docker context inspect`; set `NETGET_DOCKER_SOCKET=/absolute/docker.sock` explicitly when needed. CI can use `/var/run/docker.sock`. Tests issue only HEAD/GET and never pull images, create/delete resources, prune, or change daemon configuration. They do not inspect unrelated containers or read their environments.

The native Unix client and native TCP client both contact the actual daemon. For TCP, an owned loopback relay copies bytes directly between TCP and the existing daemon Unix socket, with at most16 owned connections and35s exchange bounds. It generates no HTTP response. Dropping the relay aborts its task and owned JoinSet. This proves TCP wire interoperability without enabling an insecure daemon listener or altering user settings.

Independent coverage: ping/version/info, filtered container list, image list, built-in network list, filtered volume list, missing-container404, advertised action/static/script examples, and mocked model choosing a version read with shared memory in the real followup. Successful container inspect and all list schema fields are verified through NetGet pair/pure schemas, while the independent daemon inspect scenario is intentionally a missing ID. Empty daemon inventories are valid; no mutation-based fixture provisioning is claimed.

The NetGet pair executes the existing server's published Python script and covers all8 client operations, inspect nested objects, query filters/boolean encoding, and native error messages. Existing tests/server/docker real Docker CLI suite remains both-role evidence and retains all server501 refusals. Pure tests cover list-vs-inspect, optional nulls, -1 sentinels, field/type/bounds refusals. Raw peers cover malformed negotiation, fragmented/chunked bodies, HTTP/schema failures with recovery, Content-Length/stream limits, whole deadline, manual handlers/injection, owned task cancellation, bounded event queues and followups.

Use the programme's serialized Cargo wrapper/shared target. Register all test files explicitly. No new private Cargo target, global installs, daemon reconfiguration or broad cleanup. New docs use AGENTS.md to match the centrally integrated documentation rename; preserve old-base files until root merges the rename.
