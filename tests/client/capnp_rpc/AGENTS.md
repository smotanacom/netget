# Cap'n Proto RPC client tests

The connect handler stores an entry (`session_test::connect_entry`); each server's echo of it,
decoded by that server and re-encoded, is the assertion that the handler's call reached the
wire intact.

- `session_test.rs`: NetGet's own server — the echo, results, a superclass method, an
  exception, local refusals; and the follow-up bound counted from the server's access log.
- `real_server_test.rs`: pycapnp's server and the Go peer's (`peer/`, code generated by
  capnpc-go from a copy of the schema carrying Go annotations and checked in), each through the
  echo, ping, add, lookup (union, group, defaults), and two exceptions.

Peers from `tests/server/capnp_rpc/install_peers.py`. No LLM calls.
