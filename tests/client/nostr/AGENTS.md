# Nostr client verification

Use the programme run_cargo.py guard and shared target. Filter the client target with nostr::. Native nak relay/CLI0.20.7, OpenSSL for an untrusted-certificate refusal peer, and Python nostr_sdk0.45.1 are required through PATH; absent peers fail. NETGET_NOSTR_PYTHON optionally selects the SDK interpreter (locally /opt/homebrew/opt/python@3.10/libexec/bin/python3); the default is python3. The existing server suite uses python3 from PATH. No daemon configuration, global installation, container or domain/event database is needed.

RealServer owns a temporary directory, HOME and the nak serve process group/death tie. A thin Python wrapper clears the child's environment and closes stdin, waits for the native relay-running log, and retains bounded fixture output for failures. The helper additionally checks the probed TCP port and retries a lost bind race. CLI producers use an explicit disposable fixture key and temp HOME so the user's default key/config is never consulted. CLI/SDK completion has a15-second deadline and kill-on-drop ownership. The wrapper does not emulate Nostr.

schema_test checks complete signed events, Unicode/control preservation, id/signature tampering, filter and correlation schemas, exact64-character subscription ids, native AND/OR/live limit0 meaning, extension refusal, unknown native reason prefixes, optional NIP-11 fields and distinct contact/relay identity, and safe refusal of deeply constructed owned values without exposing a key.

session_test uses an owned WebSocket/HTTP mock and JoinSet for its connection tasks. It checks native acceptance/refusal, EOSE live delivery, local CLOSE and already-selected late frames, replacement races/current-filter metadata, CLOSED removal, subscription/pending/duplicate bounds, nonconclusive publish deadlines, whole NIP-11 deadlines/recovery while reads stay live, HTTP/socket cancellation, queued manual dispatch with injection, bounded handler chains, challenge omission, malformed/binary/signed-event failures and startup validation. Conditions observe actual frames/events/EOF rather than fixed-second waits.

real_server_test checks independent nak relay publication, live subscription and NIP-11; nak CLI produces events and consumes/verifies NetGet signatures, rust-nostr SDK fetches/verifies the same event; a real auth-required relay proves honest refusal without NIP-42 expansion. Advertised static/script/action examples and a mocked model exercise actual native wire exchanges and shared memory, with private-key absence asserted in the model prompt/log/status paths. A NetGet pair preserves model-as-relay signing/filtering and no archive.

Run the full existing server nostr:: suite too, including its native nak/SDK both-role evidence, pcap oracle and actual connection bounds. Required tshark is discovered by its shared oracle. Experimental scope excludes positive WSS/browser runtime and new client capture/conformance claims.
